# 库边秘技（创意中八）二次开发交接说明

本包为本地/LAN 运行的「创意中八」3D 网页游戏完整开发交接包，包含源码、测试、探针脚本、运行时资产、源资产与许可/来源记录。当前版本为第二十四轮二次开发（2026-11-24）：在第二十三轮基础上，大招播报音频改为一次性播完「大狗大狗叫叫叫」短语（不再循环喊话），格斗与绅士决斗的加载卡只保留「加载中」与百分比；下文第十三轮物理参数保持不变。

## 第二十四轮：大招播报改单次短语、加载卡精简

- 大招播报音频：此前施法期间循环播放 0.87 秒的「大狗大狗」喊话段（播报暂停的 2.6 秒内会重复数轮，听感过长）。现改为施放时一次性播放完整短语「大狗大狗叫叫叫」：喊话段正常速度播完，紧接着按原顺序播放犬吠段，不循环；命中时的犬吠反馈保留。`AudioEffects` 新增 `dagouPhrase()`（两段裁切样例顺序串联、经源 buffer 时长排期），删除循环喊话的启动/停止接口与相关状态。
- 加载卡：格斗与「绅士决斗」共用同一个加载面板，现在只显示「加载中」、进度条与大号百分比，移除了「载入球桌、房间、双角色…」的物料提示；失败仍显示错误与「重试载入」。
- 技能池、决斗流程、台球物理与规则常量不变。

## 第二十三轮：技能命中可见、播报暂停、绅士决斗技能、格斗加载与界面统一

- 技能投射物可见：此前技能命中敌方时投射物在同一帧被模拟移除、视觉立即消失，造成「放了技能看不到东西」。FightView 现在为每个投射物保留 0.55 秒的落点滞留（停在最后位置、缩小上浮淡出）后才销毁，自由球/老吴出击/万杆齐发/猛犬冲锋命中后都能看清释放物建模；清除与重开路径仍立即释放资源。调试接口新增 `skills.lingered`（累计滞留次数）与 `skills.lingering`（当前滞留数）。
- 播报暂停：大招施放触发全屏播报时冻结模拟推进与攻击/技能输入，播报层按墙钟计时 2.6 秒，结束后自动恢复对局；调试接口新增 `holding` 字段，e2e 断言播报期间隔帧时间与角色位置不推进。
- 绅士决斗（创意中八第四个技能，图标为原创「决」字圆环字形，无第三方素材）：对局任意时刻可用（菜单、抽卡、结算、其它技能选球过程中除外），消耗一次技能后展开球桌领域进入格斗。决斗场与菜单入口共用 FightMode，但标题为「绅士决斗 · 胜者赢下台球比赛」、出口为「放弃决斗」并带专用确认文案；格斗胜者产生后 2.4 秒（墙钟）自动返回球局，直接把台球比赛胜利判给对应座位并弹出「决」字结算弹窗；平局或主动放弃则回到原球局继续（球局计时在决斗期间冻结，技能已消耗、不宣布胜负）。AI 不会主动发起决斗，但通过调试接口触发时同样按座位结算。
- 加载页：进入格斗（含决斗）时加载面板改为「加载中」+ 真实资源进度百分比，按 21 个加载单元统计（动作数据、球桌、房间、角色、球杆、猫、狗与 14 张粒子贴图），加载失败仍显示错误与「重试载入」；面板带进度条与 `aria-valuenow`。
- 界面统一：格斗 HUD、按钮、计分面板、技能卡、触屏键与弹窗改为台球模式同款暖色咖啡馆主题（纸色半透明面板、咖啡衬线标题、圆形杆徽、青/朱血条、琥珀怒气条、编号技能卡），沿用原响应式断点与 390px 下 2×2 技能网格；大招播报保留暗红电影化全屏层作为对比。
- 测试与边界：技能池由 3 个增至 4 个，开局抽卡固定展示全部 4 个候选、仍选 3 个；决斗不改变台球物理与规则常量。本轮实跑与构建验收记录见下方同名章节。

## 4. 核心不变量（改动前务必理解）

1. **权威状态与表现分离**：`GameController` 持有 `rule`（规则）与 `simulation`（物理）；Three.js 视图只读快照渲染，动画/特效不得回写权威球态。
2. **确定性物理**：`FIXED_DT = 1/512`，`Simulation` 为纯确定性固定步长；`PRESENTATION_TIME_SCALE = 1`（2026-11-25 关闭慢放试验，保留待手感确认）只作用于滚动相位的观感累加器，不改变物理步数、轨迹、停点距离与种子确定性。
3. **技能经权威状态机提交**：玩家与 AI 走同一 `useSkill` 接口；`skillEligible` 统一裁决相位/暂停/球权/剩余次数。
4. **假自由球**：`FakeFreeBallMachine` 为注入时间的纯状态机（10 秒寿命）；主循环按真实时间推进，`DebugApi.advanceTime` 与 `pause(enabled)` 供确定性测试。
5. **开球补力**：摆放确认后自动补到 0.88，首杆结算后还原玩家力度；HUD 力度条始终跟随权威力度。
6. **离线边界**：运行时不发起任何外部请求；新增资源必须放本地并登记到 `NOTICE` 与 `assets/asset-manifest.json`。

## 5. 定稿参数（第十三轮）

- 滚动摩擦 `ROLLING_DECELERATION = 0.7 m/s²`；滑动衰减 `SLIDING_DECELERATION = 1.96`；恢复系数 `BALL_RESTITUTION = 0.96`、`CUSHION_RESTITUTION = 0.82`；停速 `STOP_SPEED = 0.002`。
- `MAX_SHOT_SPEED = 10 m/s`，`MIN_SHOT_POWER = 0.02` → 有效出杆 0.2–10 m/s；`speed = MAX × clampedPower` 线性、无内部下限。
- HUD 力度条 `min=2`（跟随最小力度）、`max=100`、显式 `step="1"`：99 档，每档 1% = 0.1 m/s 均匀分布。
- 键盘单次瞄准 `ARROW_AIM_STEP = 0.0005 rad`（约 0.029°，A/D 与左右方向键；Alt ×0.25）；滚轮 `WHEEL_AIM_STEP = 0.0005 rad/格`；鼠标 `0.008 rad/px`（Alt ×0.12）。
- 台面：`TABLE_HALF_X = 1.27`、`TABLE_HALF_Y = 0.635`；袋半径 `0.077`；球半径 `0.0315`。
- 袋口高速球兜底：`detectFlight` 把越界球落入最近袋（2D 无跳球，唯一出口即袋口）。
- 袋角碰撞：按真实 GLB 的 45° 胶边轮廓建立胶囊线段碰撞，球心与可见胶边保持一个球半径；角袋另有衬袋背挡，中袋/角袋袋口保留可达捕获弧。`tests/view/pocketJawFit.spec.ts` 扫描 81,518 个可达停留位置。
- 镜头：瞄准/顶视/环绕模式切换使用 0.9 秒 smoothstep 缓动；模式内瞄准与环绕仍使用快速指数阻尼。
